📘 Project Overview

This repository presents a complete end-to-end machine learning system for predicting corporate bankruptcy risk using structured financial indicators of publicly listed U.S. companies.
The project integrates:

Cost-aware classification

Ensemble modeling

Temporal performance tracking

Threshold optimization

Interpretability with permutation importance

Full reproducibility through a single notebook

All outputs (charts + Excel tables) are generated by:

Cost-Aware Ensemble Intelligence for Bankruptcy Prediction.ipynb

🎯 Objectives

Build a cost-optimized bankruptcy classifier

Compare 9 ML algorithms with a unified pipeline

Handle class imbalance (≈10% bankrupt firms)

Use rolling-origin temporal evaluation

Tune models with RandomizedSearch

Implement cost-based threshold selection

Provide clear interpretability and visual analytics
